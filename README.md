# game-Veyra（游戏交流论坛）

这是一个极简优雅风格的游戏交流论坛前端示例站，使用 `React + TypeScript + Vite` 构建，结合 `Tailwind CSS` 做版式与配色，并使用 `Framer Motion + GSAP + Lenis` 实现滚动与进入动画。

## 1. 设计风格目标
- 极简中性色：芝麻黑 `#F9F8F7` + 灰阶 + 纯白，尽量避免彩色跳色，整体色相统一
- 空间感：大体量 Hero 巨幕标题，顶部导航/搜索做半透明玻璃态
- 鼠标交互：按钮胶囊形状，hover 时做平滑填充；图片 hover 做轻微缩放与位移
- 动效：页面滚动触发“由下自上”的位移与淡入；精选横滑卡片悬停轻微放大

> 说明：你要求“自定义光标会卡”，因此当前版本已去除自定义光标，恢复系统默认光标以保证流畅度。

## 2. 技术栈
- 前端：
  - React（含状态与弹窗交互）
  - TypeScript
  - Vite（打包/开发服务器）
  - Tailwind CSS（样式与组件风格）
  - Framer Motion（进入/悬停动画、弹窗动效）
  - GSAP + ScrollTrigger（滚动进入动画联动）
  - Lenis（全局阻尼感平滑滚动）
  - Radix UI（Dialog 等基础组件）
  - lucide-react（图标）
- 后端：
  - Node.js
  - MySQL（数据库）
  - mysql2（数据库驱动）

## 5. 宝塔（BT）部署：终端方式（Nginx 托管 dist）
部署思路：`npm run build` 生成 `dist/`，然后用 Nginx 直接托管静态文件，并开启 SPA 回退（刷新路由不 404）。

### 5.1 构建 dist
在服务器项目目录执行：
```bash
cd /www/wwwroot/你的站点目录
npm ci
npm run build
ls -la dist
```

### 5.2 Nginx 配置（SPA 回退）
在你的站点 Nginx server 配置中确保：
- `root` 指向 `.../dist`
- `location /` 使用 `try_files` 回退到 `index.html`

示例（按你的目录替换）：
```nginx
server {
  listen 80;
  server_name 47.96.76.147;

  root /www/wwwroot/47.96.76.147/dist;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }
}
```

修改完成后重载 Nginx：
```bash
nginx -t && nginx -s reload
```

## 8. 项目检查与修复
### 8.1 代码检查结果
经过对项目代码的全面检查，发现以下潜在问题：

1. **安全问题**：
   - 后端服务器中密码以明文形式存储在数据库中，建议使用 bcrypt 等库进行密码哈希处理

2. **配置问题**：
   - 数据库连接配置使用硬编码的默认值，建议在生产环境中使用环境变量
   - 数据库初始化时不会自动创建数据库，需要手动创建数据库

3. **功能改进**：
   - 后端服务器未实现用户会话管理，使用无状态 API 设计
   - 缺乏数据验证和清理机制
   - 未实现 API 限流功能

### 8.2 修复建议
1. **安全增强**：
   - 安装 bcrypt 库：`npm install bcrypt`
   - 修改密码存储逻辑，使用 bcrypt 哈希密码

2. **配置优化**：
   - 创建 .env 文件，存储数据库连接信息
   - 使用 dotenv 库加载环境变量

3. **功能完善**：
   - 实现用户会话管理（如使用 JWT）
   - 添加数据验证和清理
   - 实现 API 限流

### 8.3 运行建议
1. 确保 MySQL 数据库已安装并运行
2. 创建数据库（与 server/db.js 中的 DB_NAME 对应）
3. 启动后端服务器：`npm run server`
4. 启动前端开发服务器：`npm run dev`
5. 访问 http://localhost:5173 查看项目
